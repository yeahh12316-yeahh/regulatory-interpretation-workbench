# 外规解读智能体工作台信息架构与用户流程

网站名称：外规解读智能体工作台

## 一级页面

1. 首页：说明外规解读范围、支持机构类型和新建任务入口。
2. 任务中心：任务列表、机构类型、法规名称、状态、审核状态和更新时间。
3. 新建任务：机构类型、业务范围、地域、解读时点、法规上传和新旧规选项。
4. Workflow：S1、S2、S3、S5、S4、QC、审核和 Render 节点状态。
5. 解读结果：法规概览、适用性、核心要求、整体解读、逐条解读和证据链。
6. 新旧规比较：版本关系、条款映射、文本变化、变化解释和证据。
7. 人工审核：问题、原文、解读、证据、修改、退回、通过和锁定。
8. 报告中心：HTML 版本、Word 版本、审核状态、生成记录和下载。

## 核心用户路径

```text
首页
  → 新建任务
  → 选择机构类型与解读时点
  → 上传法规
  → 查看 Workflow
  → 查看适用性与法规概览
  → 查看整体解读
  → 查看条款与证据
  → 查看新旧规比较（条件具备时）
  → QC/人工审核
  → 锁定结果
  → HTML 阅读或下载 Word
```

## 页面不可省略的状态

- 处理中
- 待人工确认
- 待补充旧规
- QC 未通过
- 已退回
- 已锁定
- 生成失败
- 已发布

## 结果页结构

左栏：法规目录和筛选；中栏：法规概览、解读和条款内容；右栏：适用性状态、证据链、QC 状态和待确认事项。

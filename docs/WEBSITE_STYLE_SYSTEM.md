# 网站视觉与交互样式基线

## 视觉方向

“外规解读智能体工作台”采用黑白德勤绿工作台风格：顶部全局栏和左侧导航为黑底白字，中间正文和右侧证据链保持白底黑字，德勤绿用于 Logo、当前状态、证据轨道和可点击操作。目标是让复杂法规、条款、证据和状态可快速核验，而不是营造营销型 AI 产品氛围。

## 视觉差异点

每条核心解读使用统一的“证据编号轨道”：正文中的结论带稳定证据编号，右侧证据面板同步显示来源、页码、段落和对象类型。用户可以沿着编号完成“结论 → 条款 → 原文”的核验。

德勤绿用于主动导航、证据编号、证据轨道、链接、主要操作和已载入状态；黑色用于顶部栏和左侧导航；白色用于正文底色和顶部/左侧文字。当前任务不使用蓝色边框。用户已说明拥有授权，页面使用从 Deloitte 官方 Logo 下载页取得的白色次级 Logo；不改变 Logo 形状、不裁剪 Logo。

## 字体和排版

- 中文正文：Source Han Sans SC / Noto Sans SC。
- 英文与数字：同一无衬线字体家族的 Latin 字形。
- 页面标题：24–32px，字重 650–700。
- 区块标题：16–20px，字重 600。
- 正文：14–16px，行高 1.7。
- 条款原文：15px，行高 1.85，保持段落和条款编号清晰。
- 数字使用等宽数字或 `tabular-nums`，避免金额、比例和日期跳动。

## 布局

- 默认桌面宽度：1440px；内容最大宽度 1440px。
- 严格沿用用户附件的工作台布局：顶部全局栏；左侧任务列表、搜索和法规目录；中间法规概览、适用性判断、条款解读；右侧证据链、来源位置和证据跳转。
- 顶部全局栏为黑底白字，Logo 位于“外规解读智能体工作台”上方；不再使用“外”字图标。
- 左侧导航为黑底白字；“我的草稿”不属于当前核心闭环，已移除。
- 结果页采用左侧任务/目录栏 + 流动正文栏 + 右侧证据栏，三栏比例参考附件，不改成营销首页或卡片式仪表盘。
- 使用 1px 规则线和 8px 基础间距单位。
- 卡片只用于独立事实、状态或证据对象；不使用大面积浮夸阴影。
- 关键事实、待确认和 QC 阻断状态必须有明显但克制的语义标识。

## 交互规则

- 任何 AI 结果都显示状态：处理中、待确认、已审核或已锁定。
- 任何证据编号都可点击并定位到原文。
- 任何失败都说明失败节点、原因、影响和可执行操作。
- 页面不使用虚构的用户、法规、时间、指标或处理进度。
- 未有真实结果时显示空状态和下一步操作，不填充演示数据。

## 不采用

- 不使用第三方品牌 Logo 或品牌色复制。
- 不使用“智能革命、全面赋能、颠覆升级”等无证据营销文案。
- 不把“模型生成”显示成“监管结论”。
- 不用图标或装饰替代证据、状态和来源信息。
